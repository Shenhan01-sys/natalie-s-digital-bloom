

# Portfolio Website for Natalie Netania Sulistio

A stunning, single-page portfolio website that showcases your unique blend of HR expertise and Web3 technology skills. The design will be **feminine yet professional**, featuring glassmorphism effects, smooth animations, and a warm color palette.

## 🎨 Design System

### Color Palette
| Role | Color | Usage |
|------|-------|-------|
| Primary Background | `#FBF4EB` (Warm Cream) | Main page background |
| Secondary Background | `#FBD9E5` (Soft Pink) | Alternating sections, cards |

- **Body**: Inter (clean, modern sans-serif)

- **Framework**: React with TypeScript (already set up)

- **Fonts**: Google Fonts (Playfair Display + Inter)
- **Icons**: Lucide React icons
- **Smooth Scroll**: Native CSS scroll-behavior
- **Animations**: CSS keyframes + Tailwind animate
