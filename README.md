# Natalie Netania Portfolio

This is a personal portfolio website for Natalie Netania Sulistio, built with React, Vite, and Tailwind CSS.

## Project Structure

- `src/components`: React components
- `src/pages`: Page layouts
- `public`: Static assets

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
